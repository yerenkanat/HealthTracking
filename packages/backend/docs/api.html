Контент-API Umay

Справочные календари, протоколы Минздрава и персонализированные таймлайны, вычисляемые из даты (срок родов или дата рождения ребёнка). Личных данных здесь нет — это контент, который сторонний сервис (например, WhatsApp-бот) может присылать вовремя нужную неделю.

Base URL
/api/v1
Формат
JSON. Даты — YYYY-MM-DD. Язык — lang=ru|kk.
Авторизация
Если задан CONTENT_API_KEY, каждый запрос шлёт заголовок x-api-key. В деве ключ обычно не нужен.
Аудио
Клипы стримятся с /audio/:track/:day/:locale (поддержка Range).
