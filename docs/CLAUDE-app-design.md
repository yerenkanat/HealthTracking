# Ana-Bala · Мобильное приложение — полная дизайн-система

Спецификация для точного воспроизведения. Не «вдохновляйся» — **собирай по этим рецептам**.
Эталон макетов: `Ana-Bala App v3.dc.html` — 59 экранов, Android 360 dp. Если что-то расходится с этим файлом, прав файл.

**Можно менять:** внешний вид, тексты подписей, порядок блоков внутри экрана.
**Нельзя менять:** API, роутинг, названия полей, ключи локализации, права доступа, схему БД. Система работает на боевом сервере.

# ЧАСТЬ 1 · ТОКЕНЫ

## 1.1 Холст

```
Ширина базовая     360 dp   (проверять до 320)
Высота кадра       800 dp
Поля экрана        16 dp    ← ВСЕ горизонтальные отступы контента
Между карточками   12 dp
Внутри карточки    16 dp    (компактные — 13–14)
Шаг сетки          4
Мин. цель нажатия  48 dp
Масштаб шрифта     проверять при 130 %
```

Ни у одной карточки, кнопки, строки **нет `height`** — только `min-height`. Казахский длиннее русского: считайте, что каждая подпись переносится на вторую строку.

## 1.2 Шрифт

```html
<link href="https://fonts.googleapis.com/css2?family=Rubik:wght@400;500;600;700&display=swap" rel="stylesheet">
```

**Rubik** — единственная гарнитура (полный казахский набор: ә ғ қ ң ө ұ ү һ і). Unbounded и Manrope в приложении не используются — ломают казахский.

| Роль | px / line-height | weight | extra |
|---|---|---|---|
| Дисплей (цифра-герой) | 42–56 / 1.05 | 700 | `letter-spacing:-.03em` |
| Заголовок экрана | 24 | 700 | `letter-spacing:-.02em` |
| Заголовок раздела/герой | 20–22 | 700 | `letter-spacing:-.02em` |
| Показатель | 32–34 | 700 | `letter-spacing:-.02em`, tnum |
| Заголовок карточки | 15–17 | 600 | |
| Основной текст | 15 / 1.5 | 400–500 | |
| Метка кнопки | 15–16 | 600 | |
| Подпись | 13 / 1.45 | 500 | `color:#5B4C57` |
| Мелкая подпись | 12 | 500 | `color:#8A7A84` |
| Секция (caps) | 12 | 700 | `uppercase; letter-spacing:.08em; color:#7C6C77` |

```css
/* поверхности */

/* текст */
--ink:           #241A22;
--ink-2:         #5B4C57;
--ink-3:         #7C6C77;
--ink-4:         #8A7A84;
--ink-mute:      #A8949F;   /* шевроны, неактивное */

/* действие */

--warn:    #E08A00;  --warn-text: #8A5300;  --warn-deep:#6E4200;  --warn-bg: #FFF0DC;

--sos:     #A8002F;

/* ночь */
--n-bg:    #171218;  --n-card: #221A22;  --n-surface: #2C2429;
--n-accent:#FF89A9;  --n-ink:  #F5EBF0;  --n-ink-2:#C3B3BD;  --n-ink-3:#9C8B96;
```

**Жёсткие правила**
1. `#D6004A` — только заливки с белым текстом. Текст и иконки на светлом — `#B8003F`. Мелкий `#E8114B` не проходит AA.
2. `#A8002F` — **исключительно SOS**. Батарейка, потеря связи, пропущенный скрининг — янтарные.
3. Один акцент доминирует на экране.
4. Ночная тема только там: таймер схваток, ночное кормление, пуши на локскрине. Остальное светлое.

## 1.4 Форма и тень

```
радиусы: 999 чипы · 16 мелкие плитки · 18 кнопки/поля · 20–22 карточки · 24–26 герой
тень карточки:  0 4px 14px rgba(60,30,45,.06)
тень акцентной: 0 4px 14px rgba(60,30,45,.07)
тень героя:     0 14px 30px rgba(244,67,107,.28)
тень таббара:   0 -2px 18px rgba(60,30,45,.08)
```

**Никаких 2 px чёрных рамок с жёстким смещением** — при 130 % шрифта они рвут карточку. Вместо них хайрлайн `1px solid #EADFD9` + мягкая тень.

Иконки — текстовые глифы в цветной плитке: `♥ ◎ ☾ ✿ ▶ ⏻ ◑ ⌖ ✚ ▤ ◈ ⚖ ↑ ♡ ⌁ ✓ ! ›`

# ЧАСТЬ 3 · ПОЛНЫЙ СОСТАВ ЭКРАНОВ (59)

Формат: **№ · Название** → блоки строго сверху вниз.

## Вход и онбординг

**01 · Язык и согласие** — логотип 52 px → «Сәлем! Выберите язык» 26/700 → три радио-строки (Қазақша / Русский / English, выбранная `border:2px solid #D6004A`) → карточка согласия с чекбоксом и ссылкой «Что именно собирается →» → кнопка «Продолжить» → точки прогресса 5 шагов.

**02 · Номер телефона** — «‹» → «Ваш номер телефона» → пояснение (пароль не нужен) → поле `+7 | 707 345 22 44` с рамкой действия → подпись «Казахстан · оператор определится сам» → зелёная плашка «Номер только для входа и доставки, рассылок не будет» → «Получить код» → текстом «Посмотреть приложение без входа».

**03 · Код из SMS** — 6 ячеек 60 px (заполненные — цифра, активная — рамка `#D6004A`) → «Отправить снова через 0:24» + «Позвонить» → карточка автоподстановки кода из SMS → клавиатура.

### Что эти пять кадров означают построчно

Три числа из референса кадров **не печатаются**: «15 секунд», «обычно 5–7 секунд»
и перцентиль на плитке «Рост и вес». Причины — в `docs/DESIGN_DEVIATIONS.md`,
раздел «Детектор плача». Два обещания из референса — «работает без интернета» и
«всё считается на телефоне» — **запрещены**: аудио уходит на сервер, и об этом
сказано в `cry_privacy` и в опубликованной политике (`legal_priv_cry_b`).

#### 15a · «Ребёнок · Сегодня»

Два сегмента (`DsSegmented`), не таббар: **Где ребёнок** — карта (кадр 12),
**Сегодня** — этот список. По умолчанию открывается **Сегодня**, если у ребёнка
нет спаренного трекера: карта без брелока — это пустой экран, поставленный
заголовком. С трекером по умолчанию открывается карта.

Порядок ниже сегментов:

1. Секция **«Каждый день»** — сетка 2×2, `DsIconTile` + подпись + подстрочник:

| Плитка | Ключ заголовка | Подстрочник | Откуда число |
|---|---|---|---|
| Почему плачет | `cry_title` | последняя проверка: причина · дата, либо «Причина не определена», либо «Ещё не проверяли» | `AppController.cryHistory`, `CryResult.namesReasonAt(порог)` |
| Дневник малыша | `nb_title` | «Сегодня отмечено: N» | `summaryFor(newbornLogFor(id), сегодня)` — `feeds + diapers + sleepStretches` |
| Рост и вес | `grw_title` | последнее измерение + его дата, либо «Нет измерений» | `growthFor(id).last` |
| Прививки | `vac_title` | «Стоит уточнить: N», при N = 0 «Всё отмечено», без даты рождения — «Укажите дату рождения» | `vaccinesToCatchUp(ageMonths, vaccinesDoneFor(id))` |

  **Перцентиля на плитке «Рост и вес» нет и не будет**, пока не импортированы
  таблицы ВОЗ: `domain/child_growth.dart` отказывается от них сознательно.
  Подстрочник — это дата, а не оценка; это же и есть подпись свежести.

  Слова «просрочена» на плитке прививок нет: `domain/vaccination.dart` называет
  такое состояние `passed` и прямо запрещает читать его как «пропущена» —
  приложение не знает, что ребёнку уже сделали.

2. Секция **«Сақтық үшін» / «На всякий случай»** — строки `DsListCard`:
   Медкарта (`ei_title`), Гиды (`gd_title`).

3. Пять инструментов, привязанных к возрасту (Развитие, Прикорм, Безопасность
   дома, Болезни, Прививки), показываются только при известной дате рождения;
   вместо них — строка «Укажите дату рождения» с переходом в редактор. Это уже
   работает в `child_tools_sheet.dart` и переносится как есть.

**Баннера про плач на этом экране нет.** Референс ставит баннер-приглашение над
сеткой, в которой уже есть плитка «Почему плачет»: это два входа в один экран на
одном экране — ровно тот дефект, который в этом репозитории уже выкатывался.
Плитка остаётся (она постоянна, подписана и несёт подстрочник — то самое, что
баннер и показывал бы), баннер выброшен. Приоритет отдан плитке позицией: она
первая в сетке.

#### 15b · Первый вход

Порядок сверху вниз: герой `#FFE4EA` с иконкой записи и `cry_title` → три шага
подготовки → плашка «подсказка, не диагноз» (`cry_intro`) → **строка приватности
`cry_privacy`** → `DsBottomActionBar` с «Записать плач».

`cry_privacy` обязана стоять **выше кнопки записи**. Согласие после записи — не
согласие; это закреплено `app/test/cry_privacy_test.dart:69`. Если раскладка не
оставляет места над кнопкой — меняется раскладка, не предложение.

Три шага (это подготовка к записи, не медицинский текст):
телефон на расстоянии вытянутой руки · выключить телевизор и музыку · записывать,
пока малыш действительно плачет, пять секунд.

**Пять секунд, не пятнадцать.** `packages/cry-classifier/cry_features.py:33`
задаёт `DURATION_SEC = 5.0` и обрезает вход ровно до пяти секунд. Пятнадцать
секунд означали бы, что десять секунд плача чужого ребёнка уезжают на сервер и
выбрасываются. Число на экране равно числу в `cryRecordSeconds`.

Микрофон запрещён: не строка статуса, а состояние экрана — заголовок, объяснение
(`cry_mic_denied`) и **кнопка «Открыть настройки»** в нижней панели. Отказ без
действия — тупик.

#### 15c · Идёт запись

Кольцо обратного отсчёта (детерминированное, `value = прошло / 5`), под ним
`0:03 / 0:05` — цифрами, без существительного: и русское «секунды», и казахский
числительный посессив ломаются на согласовании.

**Кнопка «Стоп» обязательна.** Сегодня кнопка записи во время записи отключена
(`cry_insight_screen.dart:181`), то есть прервать запись собственного ребёнка
нельзя иначе как выходом с экрана. Правило остановки:

- раньше 3 секунд — запись **отменяется**, ничего не отправляется, экран
  возвращается в исходное с пояснением «Слишком короткая запись — мы ничего не
  отправили»;
- 3–5 секунд — уходит на разбор как обычно (классификатор дополняет тишиной,
  `fix_length`).

Живая волна из референса рисуется **только** если амплитуда действительно
считывается с микрофона (`CryMic` её сейчас не отдаёт). Волна, не следящая за
звуком, — это украшение в форме показания. До тех пор — кольцо.

#### 15d · Разбираем

Кольцо замерло на полном круге, поверх — индикатор обработки, заголовок
«Разбираем запись», под ним **повтор строки приватности**: отправили на разбор,
файл удаляется сразу после ответа.

**Ни «всё считается на телефоне», ни «обычно занимает 5–7 секунд».** Первое
неправда (`data/cry_classifier_client.dart` шлёт `POST`), второе — утверждение о
задержке классификатора, которую в этом продукте ничто не измеряет.

#### 15e · Результат

Карточка результата на `#DFF3EA` — **только когда причина названа**. Ниже порога
(`cry_unsure_*`) фон нейтральный, `Palette.surface`: мятой заливкой отказ
выглядит как удачный ответ — это тот же дефект, что был исправлен на главной
(«ungraded reading painted the green of a healthy one»).

Заголовок — причина, справа — `cry_confidence`. Ниже — полоски по причинам из
`analysis.ranked`. **Полоска рисуется только для причины, которая есть в
`probabilities`**: причины без вероятности на экране нет вообще. Рекомендация
печатается только выше порога — она называет причину прозой.

Плашка «подсказка, а не диагноз» (`cry_disclaimer`) — внизу, дословно; текст
медицинской границы не переписывается без клинического шлюза.

«Записать ещё раз» — в `DsBottomActionBar`, а не серединой прокрутки.

# ЧАСТЬ 4 · ЛОГИКА, КОТОРУЮ РЕДИЗАЙН НЕ ЛОМАЕТ

1. **Главная зависит от этапа.** Беременность → неделя и малыш. Есть ребёнок → возраст и рост. Ни того, ни другого → цикл. Показатели браслета всегда ниже героя.
2. **Календарь один, вкладок сверху нет.** Беременна — цикл скрыт полностью. Родила — развитие вместо беременности. Цикл возвращается после первых месячных. Переключение — событием в «⋯» («Тест положительный», «Я родила»), не табом. Приоритет: беременность → развитие → цикл.
3. **Без устройства приложение полноценно** — ручной дневник, а не заглушка с апселлом.
4. **Свежесть данных подписана всегда.** Карта без времени последнего обновления врёт.
5. **Красный только SOS.** Остальное тревожное — янтарное.
6. **Никаких диагнозов.** «Подсказка, а не диагноз», «ориентир, а не норматив». Красные флаги отдельным блоком, не под «читать дальше». 103 внизу.
7. **Приватность в интерфейсе.** Запись плача уходит на наш сервер только для
   разбора и не сохраняется — это сказано на самом экране, выше кнопки записи, и
   так же в политике. Прежняя редакция этой строки говорила «плач считается на
   телефоне»: сборки, которая это делает, не существует, инференс живёт в
   `packages/cry-classifier`, и обещание, которое опровергается собственным
   сетевым трафиком, хуже отсутствия обещания. Близкие видят детей, не здоровье
   мамы. Маршруты 90 дней.
8. **Ночь — крупные цифры, действие в нижней трети, вибрация.**
