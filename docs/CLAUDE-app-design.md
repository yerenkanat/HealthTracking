# Ana-Bala — мобильное приложение · дизайн-спека для Claude Code

**Что можно менять:** только внешний вид — цвета, типографику, отступы, радиусы, тени, порядок блоков внутри экрана, тексты подписей.
**Что нельзя трогать:** API-вызовы, роутинг, названия полей, бизнес-логику, ключи локализации (меняйте значения, не ключи), схемы БД, права доступа. Приложение работает на боевом сервере.

Источник истины по макетам: `Ana-Bala App v3.dc.html` (55 экранов, Android 360 dp).

---

## 1. Платформа и холст

| Параметр | Значение |
|---|---|
| Базовая ширина | **360 dp** (Android), проверять до 320 |
| Высота кадра макета | 800 dp |
| Поля экрана | 16 dp |
| Между карточками | 12 dp |
| Шаг сетки | 4 |
| Мин. цель нажатия | **48 dp** |
| Масштаб шрифта | проверять при **130 %** |

Ни одна карточка, кнопка или строка **не имеет фиксированной высоты** — только `min-height`. При 130 % они растут, а не обрезают текст. Казахские строки длиннее русских: верстайте так, будто каждая подпись переносится на вторую строку.

## 2. Шрифт

Единственная гарнитура — **Rubik** (полный казахский набор: ә ғ қ ң ө ұ ү һ і).

```html
<link href="https://fonts.googleapis.com/css2?family=Rubik:wght@400;500;600;700&display=swap" rel="stylesheet">
```

| Роль | Размер / интерлиньяж | Начертание |
|---|---|---|
| Дисплей | 28 / 32, `letter-spacing:-.02em` | 700 |
| Заголовок экрана | 22 / 28 | 700 |
| Крупный показатель | 34–56, `tnum` | 700 |
| Заголовок карточки | 15–17 | 600 |
| Основной текст | 15 / 22 | 400–500 |
| Метка кнопки | 14–16 | 600 |
| Подпись | 13 | 500 |
| Секция (caps) | 12, `letter-spacing:.08em`, uppercase | 700 |

Никаких Unbounded/Manrope в приложении — они ломают казахский.

```
Сон/курс #6B4EE6 · текст #4C31C4 · фон #ECE6FF
SOS     #A8002F  (только экстренное)

Тёмная тема (ночь): фон #171218 · карточка #221A22 · поверхность #2C222C
                    акцент #FF89A9 · текст #F5EBF0 · вторичный #C3B3BD / #9C8B96
```

**Правила цвета**

1. `#D6004A` — только заливки с белым текстом. Для текста и иконок на светлом — `#B8003F` (мелкий текст #E8114B не проходит AA).
2. Красный `#A8002F` — **исключительно SOS**. Всё остальное тревожное — янтарное.
3. Один акцент доминирует на экране.
4. Тёмная тема только там, где ей место: таймер схваток, ночное кормление, пуши на локскрине. Остальное — светлое.

## 4. Форма и тень

- Радиусы: **16** (мелкие плитки) · **18** (кнопки, поля) · **20–22** (карточки) · **24–26** (герой-блоки) · `999px` (чипы).
- Тень одна: `0 4px 14px rgba(60,30,45,.06)`; у героя `0 14px 30px rgba(244,67,107,.28)`.
- Хайрлайн `1px solid #EADFD9` вместо обводок. **Никаких 2 px чёрных рамок с жёстким смещением** — при 130 % шрифта они рвут карточку.
- Иконки — текстовые глифы (♥ ◎ ☾ ✿ ▶ ⏻ ◑ ⌖) в плитке 36–46 px с цветной подложкой.

## 5. Компоненты

**Кнопка.** Основная: `#D6004A`, белый текст, `min-height:52px`, радиус 18, 600. Вторая: белая с границей `#EADFD9`. Текстом: `#B8003F`, `min-height:44px`.

**Строка списка.** `min-height:68px`, иконка 40–44 в плитке, заголовок 15/600 + подпись 13/#5B4C57, шеврон `›` цвета `#A8949F`. Разделитель — `1px solid #F3EAE6` внутри карточки, не между карточками.

**Чип.** Радиус 999, 13/600. Выбран: `#241A22` + белый. Обычный: белый + граница. Статусные: норма `#DFF3EA/#0E7A54`, внимание `#FFF0DC/#8A5300`, свежесть `#FFE4EA/#B8003F`.

**Переключатель.** 48 × 28, вкл `#17A97A`, выкл `#E3D5DB`, кружок 22 белый.

**Пустое состояние.** Плитка 48, одна причина, одно действие. Не иллюстрация на пол-экрана.

**Таб-бар.** 4 вкладки: **Сегодня · Календарь · Ребёнок · Профиль**. Белая карточка радиус 20, тень вверх `0 -2px 18px rgba(60,30,45,.08)`, активный `#B8003F`. Подписи переносятся в две строки (казахский длиннее) — высота бара растёт, многоточия нет.

## 6. Логика экранов, которую нельзя ломать при редизайне

**Главная зависит от этапа.** Беременность → неделя, размер малыша, «что с вами» / «что с ним», быстрый лог (шевеления, самочувствие, вес). Есть ребёнок → возраст, навыки, перцентили. Ни того, ни другого → цикл и самочувствие. Показатели браслета всегда ниже — они не главные.

**Календарь один, вкладок сверху нет.** Режим определяется этапом: беременна — цикл скрыт полностью; родила — развитие вместо беременности; цикл возвращается после первых месячных. Переключение — событием («Тест положительный», «Я родила») в меню «⋯», а не табом. Приоритет при конфликте: беременность → развитие → цикл.

**Без устройства приложение полноценно.** Экран «Здоровье без браслета» — ручной дневник со сканом тонометра, а не заглушка с апселлом.

**Тревога и цвет.** Свежесть данных подписана всегда («2 минуты назад»). Красный только SOS. Батарейка, потеря связи, пропущенный скрининг — янтарные.

**Медицинские формулировки.** Никаких диагнозов: «подсказка, а не диагноз», «ориентир, а не норматив». Красные флаги — отдельным блоком, не под «читать дальше». Внизу — 103.

**Приватность.** Плач разбирается на телефоне, записи не уходят на сервер. Близкие видят детей, но не здоровье и цикл мамы. Маршруты хранятся 90 дней.

## 7. Чек-лист перед мержем

- [ ] 360 dp и 320 dp — ничего не обрезано
- [ ] 130 % шрифта — карточки выросли, текст не срезан
- [ ] Казахская локаль — подписи табов и кнопок переносятся, не режутся
- [ ] Контраст: мелкий текст на кремовом ≥ 4.5:1
- [ ] Цели нажатия ≥ 48 dp
- [ ] Красный нигде, кроме SOS
- [ ] Тёмная тема только на ночных экранах
