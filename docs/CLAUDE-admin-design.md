# Ana-Bala — админ-панель · дизайн-спека для Claude Code

**Что можно менять:** только внешний вид — цвета, шрифты, плотность таблиц, отступы, порядок колонок, тексты подписей и пустых состояний.
**Что нельзя трогать:** запросы, роли и права, схему данных, статусы заказов, названия полей, экспорт-форматы. Панель работает на боевом сервере, ей пользуются каждый день.

Источник истины по макетам: `Ana-Bala Admin.dc.html` (84 кадра, 1440 × 900).

---

## 1. Почему админка выглядит иначе, чем приложение

Оператор смотрит в неё восемь часов и работает с клавиатуры. Поэтому здесь **плотные таблицы вместо карточек-подушек**, мелкие радиусы, моноширинные цифры и минимум цвета. Тёплую палитру приложения сюда переносить не нужно.

| | Приложение | Админка |
|---|---|---|
| Строка списка | 68 px | **40 px** |
| Базовый текст | 15 px | **13 px** |
| Радиус карточки | 20–26 | **10** |
| Цвет | акцент на экран | только статус |

## 2. Холст и сетка

- Рабочая область **1440 × 900**, сайдбар 216 px фикс., контент `flex:1; min-width:0`.
- Топбар 56 px: заголовок 17/700 + подпись 13/#7A7076 + действия справа.
- Поля контента 22 px, между блоками 12–16 px.
- Кнопки топбара `height:34px`.

## 3. Шрифты

```html
<link href="https://fonts.googleapis.com/css2?family=Manrope:wght@400;500;600;700;800&family=JetBrains+Mono:wght@400;500&display=swap" rel="stylesheet">
```

- **Manrope** — весь интерфейс. `body { font-variant-numeric: tabular-nums }` обязательно: числа в колонках должны выравниваться.
- **JetBrains Mono** — номера заказов, артикулы, серийники, время, ключи API.

Шкала: заголовок страницы 17/700 · заголовок карточки 15/700 · метрика 26/800 · таблица 13 · шапка таблицы 11/700 uppercase `.06em` · подпись 12/#7A7076.

## 5. Компоненты

**Таблица.** `display:grid` с явными `grid-template-columns`; гибкие колонки оборачивать в `minmax(0, 1fr)`, иначе длинный текст рвёт сетку. Строка `padding:10px 16px`, разделитель `1px solid #F2EEEB`. Строка, требующая внимания, красится фоном `#FBF0F3` или `#FDF6EA` — не текстом.

**Статус-чип.** `border-radius:5px; padding:3px 8px; font-size:12px; font-weight:700`. Новый — `#C2003F` на белом тексте, собран — `#FDF6EA/#8A5A00`, в пути и оплачен — `#EDF5F1/#1E7A54`, доставлен — `#F0EDEA/#544C51`.

**Кнопки.** Основная `#C2003F`, белый текст, радиус 8, высота 34–38. Вторая — белая с границей `#D8D2CE`. Опасная — `#A8002F` или белая с границей `#E8C3CF` и текстом `#C2003F`.

**Карточка-метрика.** Подпись 12/#7A7076 → число 26/800 → комментарий 12. Комментарий обязателен: «26 шт» ничего не значит, «хватит на 4 дня при поставке 12» значит всё.

**Галерея форм и диалогов.** Две колонки `1fr 1fr`, `align-items:start`, внутри каждой — `flex-direction:column; gap:18px`. **Панели распределять по высоте, а не через одну**: доступная высота 802 px (900 − 56 топбар − 40 padding), сумма панелей в колонке не должна её превышать.

**Модалка.** Ширина 560–600, радиус 12, тень `0 18px 44px rgba(30,20,26,.22)`, подложка `rgba(30,20,26,.42)`. Футер: слева пояснение 12/#7A7076, справа «Отмена» + основное действие.

## 6. Правила поведения, которые нельзя ломать

**Ничего не удаляется.** Товар с историей движений уходит в архив; отменённый заказ — это статус; журнал действий не редактируется и хранится 3 года. Полное удаление доступно только для сущностей без истории (неопубликованный урок, черновик).

**Модалка или страница.** Модалка — короткое действие с возвратом на тот же экран. Страница — работа дольше минуты (приёмка, редактор, расписание). Подтверждение — необратимое или затрагивающее многих. Полная карта на кадре «27 · Карта действий».

**Приёмка принимает факт, а не накладную.** Расхождение — не ошибка кладовщика, а претензия поставщику; себестоимость партии пересчитывается с учётом брака.

**Публикация контента.** Двуязычность обязательна: без казахской версии кнопка «Опубликовать» заблокирована. Медицинский текст — только после проверки врачом.

**Доступ к чувствительному.** Показатели здоровья и геолокация — только владелец, каждый просмотр в журнале с указанием причины. Сегменты нельзя строить по данным здоровья.

**Дашбордов два.** Владельцу — деньги, «что горит», люди, удержание и «решение недели». Оператору — очереди задач. Не смешивать.

## 7. Роли

| Роль | Видит |
|---|---|
| Владелец | всё, включая финансы, здоровье и геолокацию (с записью в журнал) |
| Оператор | заказы, клиенты, поддержка, экстренные |
| Продавец | заказы, витрина, остатки, контакты — без маржи и без детей |
| Кладовщик | склад, приёмка, отгрузка, инвентаризация |
| Контент-редактор | статьи, календари, аудио, курс; описания товаров без цен |

Новая роль наследует минимум и добирает права поштучно.
